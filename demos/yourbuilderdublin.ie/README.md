# Your Builder Dublin concepts

Static client presentation published by GitHub Pages at https://walkcat.net/demos/yourbuilderdublin.ie/.

Open index.html for the comparison hub. The three concepts are everyday.html, renovation.html and construction.html. All paths are relative to this directory; no build step or external services are required.

Property images are generated illustrations. Forms are demonstration-only and do not send or save enquiries. The pages retain noindex,nofollow while they are client concepts. Font licenses are included in assets/fonts.

The original editable concept package is maintained in Clients/daniel-mirt-concepts in the agency workspace.
